Sales Dashboard – Power BI

This project is an interactive Sales Dashboard created in Power BI to visualize and analyze sales performance.
It helps identify revenue trends, top-performing products, customer segments, and regional growth opportunities.

🔹 Features

Revenue analysis by region, product, and customer segment

Dynamic filtering using slicers

Monthly & yearly trend analysis

KPIs: Total Sales, Profit Margin, Top Products

Interactive charts for better decision-making

🔹 Tools & Technologies

Power BI Desktop

Data Modeling (Relationships, Measures, DAX)

Data Cleaning (Power Query)
